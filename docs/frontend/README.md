# Frontend notes

See the root `README.md` (architecture, quickstart, model swap), `docs/demo-script.md`, `docs/performance.md` and
`docs/science/spatial-model.md`.

## Main journey (photo-first)
Home (attention-ranked fields, "Start here") → Check this field → one photo (camera / gallery / example) → automatic
on-device pipeline (`src/pipeline/check.ts`) → result: status + condition, **What to do** (Today / Next / If it gets
worse), evidence strength, what the model saw, guidance with sources, regional context, expert-review share (preview +
confirmation), scouting map (24 h / 3 d / 7 d, uncertainty circle), weather + climatology, follow-up, data origin.
Follow-up is asked only when the photo shows no plant or a whole plant ("take a closer photo of one leaf").

## Conventions
- Views call store actions only; storage (`src/storage.ts`), workers (`src/runtime/workerClient.ts`), models
  (`src/model/*`), engine (`src/engine/localEngine.ts`), sync (`src/sync/sync.ts`) stay out of views.
- Strings: semantic ids in `src/i18n/en.ts` (+ `fr.ts`); `rw.ts`/`sw.ts` are generated by `scripts/translate-ui.ts`
  (machine translation, labelled in the UI). Dynamic results are translated after the decision (`src/model/translation.ts`)
  — ids, numbers and statuses never change (tested).
- Icons: one subset font (`scripts/build-icons.mjs`); `npm run check` fails on an icon not in the subset.
- Status always pairs colour with icon and words; maps have text alternatives (ranked scouting list).

## Offline / persistence
Check saved first (AsyncStorage → localStorage on web); a failed write shows "Not saved on this phone" with retry
(tested in `tests/persistence-journey.ts`). Photos: web data URL (downscaled ≤1280 px), native copy into the app's
`documents/photos`. Weather package synced when online (≤ every 6 h, partial sync kept) and used offline with its age.

## Tests
`npm run check` (tsc, adapters, 23 domain/flow tests, icon audit); browser: `tests/photo-journey.ts` (online/offline,
`--locale=rw`), `tests/persistence-journey.ts`, `tests/screenshots.ts` (phone + desktop tour), `tests/location-journey.ts`
and `tests/http-smoke.ts` (optional server mode).
