# Architecture and assumptions

A small FastAPI Python service owns agricultural computation; Expo/React Native TypeScript owns presentation. JSON Schema draft 2020-12 and deterministic JSON fixtures form the shared boundary. No database, cloud service, model weights or geospatial library is required. Functions remain independent of HTTP. The MockVLMAdapter accepts canonical observations; it does not assert anything about Liquid's eventual raw output. Add real parsing there when the model interface is known.

Bootstrap intentionally returns synthetic coffee rust suspicion, uncertainty and simple inspection/review text. Sources are empty, environmental recency is unavailable, and map features are empty. No inferred disease probability, spread forecast or chemical instruction is delivered. Confidence is a synthetic signal score, not calibrated infection probability. The synthetic coordinate is WGS84 and does not represent an actual farm. Time is fixed for reproducibility and therefore stale. Backend owners must replace generic guidance with sourced knowledge before labeling it supported.

Shared field names are stable semantic identifiers. Only English fixture text exists; unsupported locales must be disclosed, never presented as translated. Existing source registry is empty. Offline mock access works without backend; durable device storage, queues, synchronization, camera and real inference remain worker-owned implementation tasks.

Ownership after handoff: backend owns backend/, docs/backend/, shared/ and published API/contract changes; frontend owns frontend/ and docs/frontend/. Architecture owns bootstrap/root documentation until readiness, then freezes it. Backend is integration owner, and may update common interface docs with shared changes. No competing root writes. Propose incompatible changes through live mailboxes and require both role acknowledgements. Integrate tested frontend commits in integration worktree; separate passing branches do not prove joint integration.

Original role prompts are preserved byte-for-byte in docs/prompts/ and remain at launch root under their original filenames. Read the full original role prompt for overnight responsibilities.
